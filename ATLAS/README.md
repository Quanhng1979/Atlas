# Atlas

> A Personal Life Operating System built with Excel + VBA.

## Vision

Atlas is a modular, scalable and maintainable Life OS designed to manage goals, tasks, habits, finance, health and productivity through a professional software architecture.


- Atlas.Infrastructure
- Atlas.Automation
